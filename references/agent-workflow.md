# From source to a finished artifact

Read when acquiring material, choosing the next action, or resolving a coverage gap. Scale this workflow to the requested report, lesson, chapter or course.

## 1. Establish access and tools

Open the actual input. For a series, establish the lecture list and distinguish recordings from slide-only sessions. Identify document versions, figures and appendices; or a code entrypoint and relevant input.

Check the needed tools with a representative output. Reuse installed tools and prepare missing dependencies within authorization. Ask only about decisions that change the work, after exploring facts available in the environment.

If access fails, try an appropriate original-source alternative: an official course page, source repository, supplied copy or available transcript. Keep the missing portion as a gap. A third-party summary cannot establish inspection of the original.

## 2. Acquire evidence by material

- Video: inspect title, duration, chapters, original cover, subtitles and formats before downloading. Prefer manual subtitles, preserve timing and choose the highest usable downloadable resolution. See video-learning.md.
- Document or paper: read the argument and needed appendices, match definitions and illustrations to context, and prefer original figure assets when available. Inspect selected images and vector renderings before describing them.
- Audio or images: use available audio/transcripts and directly inspect supplied diagrams or notes. Preserve timestamps or file locations, identify unreadable content and do not invent missing visual frames.
- Code: trace an input through modules, state changes and output. Run a bounded example where it affects the explanation. Distinguish observed and inferred behavior.
- Data: establish units, missing values, denominators, aggregation and comparison conditions. Compute relevant quantities before plotting; do not invent measurements.

A short working note with concept, source location and unresolved issue is sufficient. No fixed JSON schema is required, and production records stay outside the learner's text.

## 3. Split and integrate

Split long inputs at chapters or coherent concepts. Videos longer than 20 minutes or with more than 300 subtitle entries need segments. Use a small overlap where reasoning crosses boundaries.

Each segment retains its goal, core claims, mechanism, formulas/code, visual locations and ambiguities. Read the active segment with shared notation and coverage notes. Integrate the whole outline, fill missing prerequisites and remove repetition.

Use subagents only when current authorization permits them. Supply bounded segments and concrete return requirements, then integrate one coherent narrative. Sequential segmentation remains valid.

## 4. Explain and connect to use

Start with a concrete problem. Introduce objects, assumptions and operations when needed, then work through an input to its result. Explain decisive mathematical transformations and local symbols. Preserve source numbers and identify teaching calculations.

Choose a visual for a specific difficulty. Compare nearby frames; prefer the final populated readable state of progressive slides. Crop or redraw an unreadable relationship with attribution.

For learning tasks, connect mechanisms to practical decisions and move from a complete example to guided work and an independent variation with reasoned answers. Other reports retain their requested argument without mandatory exercises.

## 5. Implement

Use working templates and helpers instead of repeatedly writing math, assets and layout. HTML uses scripts/build-html.mjs; an existing Markdown route or the requested LaTeX route may also apply.

Define interaction state calculations before animation. Graphics, labels, numbers and explanations read the same result. Provide pause and manual inspection; static content must preserve the lesson.

Use compact citations near supported claims and consolidate repeated records. Necessary figure times and conditions stay visible.

## 6. Verify and repair

Identify what failure a check would detect and what correction would follow. Run relevant examples, inspect selected figures, check reasoning and solve exercises. Build the delivered artifact.

When available, inspect an allowed rendering at desktop and narrow widths. Test meaningful parameter values, pause, reset, links and source expansion. Inspect print separately when included. Respect tool policies; do not route around a blocked action. State unavailable visual evidence accurately.

Repair concrete omissions, incorrect reasoning, inconsistent figures or unusable output. Recheck affected content and layout, reusing settled evidence. Do not manufacture findings, rerun unchanged checks or optimize for a score.

Finish when requested scope is covered and known blockers are resolved. Otherwise deliver useful authorized work with the specific unmet requirement. Preserve source locations, notation and accepted work for continuation.
