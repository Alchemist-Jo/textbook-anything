# Fandol web fonts

These WOFF2 files were converted from Fandol v0.3 OpenType fonts distributed with TeX Live. Only the storage format was changed; the glyph outlines and font names were retained.

- FandolSong Regular/Bold: Chinese prose.
- FandolHei Regular/Bold: headings, controls and figure labels.
- FandolFang Regular: Chinese code text.

Upstream package and original OpenType distribution: https://ctan.org/pkg/fandol

Fandol is by Clerk Ma and Jie Su. See Fandol-COPYING.txt for GPL-3.0 and the font embedding exception, and Fandol-README.txt for the upstream README. The font license is also preserved in generated HTML.

The build script embeds these fonts. End users do not need a font installation or network access.
